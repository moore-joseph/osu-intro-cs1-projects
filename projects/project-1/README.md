# Project 1 - Favorite Animal

This is a small introductory Python program that asks the user to enter their favorite animal and then prints a short message in response.

Originally written in January 2022 for OSU CS161 and later refactored to follow cleaner Python structure and modern style.

## How to Run

```bash
python3 projects/project-1/animal.py
```
## Example

```
Please enter your favorite animal: wolf
Your favorite animal is the wolf.
```
